    \caption{\textbf{OmniTrace reads what a model used from the pass that generates the answer.}
    Text, images, audio, and video share one input sequence, cut into source units (a passage, an image, a second of audio or video). While a sentence is generated, OmniTrace sums the late-layer attention mass that falls on each unit and labels the units that stand out among those of the same modality: source ids for text and images, time intervals for audio and video. The attribution is then tested by intervention: hiding the labelled units behind content-free placeholders lowers the probability of the response far more than hiding random units, and more than hiding the sources the model itself cites.
